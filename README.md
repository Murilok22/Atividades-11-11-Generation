# 📓 Portfólio de Atividades em Python

Este notebook reúne uma série de exercícios práticos desenvolvidos para consolidar conceitos fundamentais da linguagem Python, abrangendo desde lógica de programação básica até manipulação e análise de dados.

## 🚀 Tecnologias Utilizadas
- **Python 3**
- **Pandas** (para análise de dados estruturados)
- **Google Colab** (ambiente de execução)

---

## 🛠️ Atividades Desenvolvidas

### 1. 🔄 Estrutura de Repetição Dinâmica (`while`)
- **Descrição:** Implementação de um laço de repetição incremental baseado em um limite dinâmico fornecido pelo usuário.
- **Conceitos aplicados:** Entrada de dados (`input`), conversão de tipos (`int`), e controle de fluxo com `while`.

### 2. 🚗 Gerenciador de Cadastros (Listas)
- **Descrição:** Um sistema interativo simples que permite cadastrar e excluir modelos de veículos em uma lista.
- **Conceitos aplicados:** Manipulação de listas (`append`, `pop`), laços `for` e condicionais interativos.

### 3. 🔑 Manipulação de Estruturas de Chave-Valor (Dicionários)
- **Descrição:** Criação, leitura, atualização e inserção de dados em estruturas do tipo dicionário (`dict`) para simular o controle de saldos de contas.
- **Conceitos aplicados:** Busca por chave, métodos `.keys()`, `.values()`, e atualização de elementos.

### 4. 📊 Análise de Dados com Pandas
- **Descrição:** Importação de uma base de dados externa em formato CSV contendo informações de saldos e visualização inicial de estatísticas descritivas básicas.
- **Conceitos aplicados:** Leitura de arquivos (`read_csv`), visualização estruturada (`display`), informações estruturais (`info()`) e estatística descritiva (`describe()`).
